Detect Flakes

To utilize the GMM Detector, go to the Detect Flakes tab.
To use the flake identifier, you must have the following:

  1. A folder with your images. Images must be in either tif, png, or jpg format.
  2. A prepared model for the material you want to use. Please make sure all model details match the setup used for imaging.
  3. A flatfield image of the plain substrate.

Flatfield specifications:
Do not use a substrate image with large objects in view. Small particles in the image may be unavoidable, and should not affect the detection significantly. Do not use a cropped image. The flatfield image should be the same color as the substrate of the chip of interest. The flatfield image should be taken on the same setup the detection is run on.

Database

To utilize the database, go to the Database tab.
The database interface is not currently implemented. If you choose to save to the database, detected flakes will be saved in Box in Quantum Device Lab > External Optical Cataloger. If you do not choose this option, detected flakes will be saved in a folder named 2DMatGMMoutput in the same place the input image folder was saved.
